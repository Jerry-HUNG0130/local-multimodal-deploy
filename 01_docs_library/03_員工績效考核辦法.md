# 員工績效考核辦法

## 第一章 總則
### 第 1 條 目的
為客觀評價員工之工作能力、專案達成率與職業素養，將考核結果做為公司獎金發放、薪資調整、職務晉升及教育訓練之重要依據，特訂定本辦法。

### 第 2 條 考核對象及頻率
1. **考評群體**：全體通過試用期且任職滿三個月之正式員工。
2. **考核周期**：公司採取「一年雙考」制度，分為年中績效考核（考核期間為當年1月1日至6月30日）與年終績效考核（考核期間為當年7月1日至12月31日）。

## 第二章 考核維度與評分權重
### 第 3 條 考核三大維度 (360度評分架構)
員工之整體績效分數 (總分 100 分) 主要由下列三個維度進行加權計算：
1. **KPI 目標達成率 (佔比 60%)**
   * 以期初設定的 OKR 或專案節點為客觀基準。
   * 評估範例項目：程式碼產出品質、工單處理效率、AI 監控系統異常搶修回應時間（SLA）、產品上線時程的準確率。
2. **核心職能與團隊協作 (佔比 25%)**
   * 強調跨部門溝通、團隊貢獻分享與技術指導的意願。
   * 包含對公司開發文化之認同度，以及參與例行 Code Review 的積極度。
3. **出勤與工作紀律 (佔比 15%)**
   * 依據《工時與考勤管理制度》、遲到早退紀錄及《資訊安全管理規範》是否違反。
   * 如曾發生帶有密碼之隨身碟違規存取公司資料，此項分數扣至零分。

## 第三章 考核等級與結果運用
### 第 4 條 等級劃分
考核結果最終將進行常態分配（Curve Distribution），分為五個級別：
* **S 級 (傑出 - 前 10%)**：展現卓越能力，超額完成挑戰性目標，對公司營收或技術框架有重大突破貢獻。
* **A 級 (優良 - 20%)**：表現超越期望，不僅完成日常任務更主動優化現有流程。
* **B 級 (達標 - 60%)**：完全履行職位要求，穩定產出並達成專案里程碑。
* **C 級 (需改善 - 5~10%)**：部分目標未達成，或在團隊合作、專業技術上出現明顯短板，需主管介入輔導。
* **D 級 (不適任 - 1~5%)**：嚴重違反紀律、頻繁發生重大線上系統故障而未依 SOP 處理，或連續兩期獲得 C 級。

### 第 5 條 績效面談與PIP改善計畫
1. **結果面談**：各部門主管必須於考核結束兩週內，與下屬進行一對一績效面談（One-on-One），詳細說明其優缺點並規劃新年度期望。
2. **績效改善計畫 (PIP)**：對於考核獲列 C 級或 D 級之員工，主管需與人資部門偕同啟動為期三個月的「績效改善計畫（Performance Improvement Plan）」。若 PIP 結束後覆核仍未通過，公司得依循勞動基準法終止聘僱。

## 第四章 爭議處理
### 第 6 條 申訴機制
員工若對自身的績效考核結果或直屬主管之評價有重大異議且掌握客觀證據（如：專案進度 Email、Commit 紀錄），得於收到成績之 7 個工作日內，親自向各事業群處長或人資部提出申訴。由高層組成小組重新檢視該考核的公正性。
